# ALIADOS DEL SOL
## Design System — Guía de Marca

*Política de sostenibilidad de GEENERA · Manual base: Abril 2023 (Agencia GENOMA) · Actualizado con lineamientos digitales y editoriales 2026*

---

## 1. Sobre la marca

**Aliados del Sol** es la política de sostenibilidad de GEENERA: una iniciativa que conecta empresas, líderes y organizaciones comprometidas con la construcción de un futuro más eficiente, competitivo y sostenible.

> "El sol es un aliado para que la vida siga su curso, y como recurso natural se hace vital para todo y para todos."

**Propósito de marca:** transformar ese recurso natural en una oportunidad de impacto real — para hogares, para empresas y para quienes conectan a unos con otros.

**Territorio de marca:** transformación energética + confianza + red de aliados.

**Frase guía:** *"Las grandes transformaciones comienzan con grandes aliados."*

### Categorías dentro del ecosistema
- **EMI (Emisor de Oportunidades Estratégicas):** aliados con acceso directo y credibilidad ante líderes empresariales con poder real de decisión sobre inversión, sostenibilidad y eficiencia energética. Un EMI no se define por cuántos contactos tiene, sino por el acceso y la confianza que ha construido.
- **Linker:** aliados que refieren empresas interesadas en proyectos solares a cambio de comisión.
- **Programas Hogares / Industrias:** líneas de producto según el público objetivo (residencial vs. empresarial).

## 2. Logotipo

### Logosímbolo
El símbolo combina un **círculo sólido (el sol)** con un **arco/anillo abierto** que lo envuelve parcialmente, evocando movimiento y energía en expansión. El nombre "ALIADOS DEL SOL" se compone en dos líneas, superpuesto parcialmente al símbolo mediante un bloque de color sólido.

### Plano de construcción
El manual oficial define la retícula de proporciones del logosímbolo mediante un módulo base (1x), con el símbolo construido a partir de múltiplos y fracciones exactas de ese módulo (incluye referencias como 20,3x de ancho total, 19,3x, 14,2x, 4,1x, 1,3x, 0,4x y 0,2x para los distintos elementos). **No redibujar ni recalcular estas proporciones manualmente** — usar siempre el archivo maestro del logo.

### Versiones disponibles
- **Versión color** (principal) — sobre fondo blanco/claro.
- **Versión escala de grises.**
- **Versión positivo/negativo** — para fondos oscuros o fotográficos.
- **Lockup institucional "Tu energía GEENERA"** — variante del isotipo de GEENERA que acompaña piezas co-marcadas con Aliados del Sol (ver piezas gráficas de referencia).

### Modificaciones inaceptables
El manual dedica una sección explícita a esto — como regla general:
- No deformar, rotar ni inclinar el símbolo.
- No alterar las proporciones entre el círculo, el arco y el bloque de texto.
- No cambiar los colores oficiales por variantes no aprobadas.
- No aplicar efectos (sombras, biseles, degradados) sobre el logotipo.
- No recomponer el logo tipográficamente con otra fuente.

*(Para el detalle gráfico exacto de cada modificación inaceptable, remitirse a la página correspondiente del manual PDF — esa página es puramente visual y no debe reinterpretarse de memoria.)*

### Área de seguridad
Mantener siempre un espacio de protección alrededor del logotipo libre de otros elementos gráficos o texto, proporcional al módulo base de construcción.

## 3. Paleta de color

### Colores principales (gama cromática oficial)

| # | Nombre de uso | CMYK | RGB | Pantone |
|---|---|---|---|---|
| 1 | Amarillo Sol | 0 / 22 / 93 / 0 | 255, 202, 5 | 7409 C |
| 2 | Naranja Aliados | 0 / 62 / 91 / 0 | 243, 121, 32 | 1645 C |
| 3 | Naranja Dorado | 0 / 41 / 91 / 0 | 249, 165, 26 | 7548 C |

> Estos tres tonos —del amarillo sol al naranja profundo— se combinan para dar efecto de volumen al símbolo y deben mantenerse como la paleta base en todas las aplicaciones corporativas, señalética y material de comunicación. Para impresión, usar siempre el desglose CMYK indicado.

### Escala de grises (para uso en aplicaciones monocromáticas)
- Gris 1 — 22%
- Gris 2 — 16%
- Gris 3 — 34%

### Uso del color en piezas de comunicación
En piezas fotográficas (redes, pauta digital), el manual visual permite:
- **Overlays de degradado** en tonos azul/morado sobre fotografía, para dar contraste y permitir tipografía blanca o amarilla legible encima.
- **Bloques sólidos naranja/amarillo** para CTAs, cifras destacadas y numeración de pasos.
- Fondos fotográficos reales (paneles solares, personas, industria) combinados con el sistema de color de marca — nunca color de marca aislado sin contexto humano/energético.

## 4. Tipografía

**Fuente oficial: Titillium Web**

| Peso | Uso |
|---|---|
| **Bold** | Titulares principales, cifras de impacto |
| **SemiBold** | Subtítulos, llamados a la acción |
| **Regular** | Cuerpo de texto, párrafos explicativos |
| **Light** | Información complementaria, pies de página, notas secundarias |

Ejemplo de tono tipográfico por peso (según el manual oficial):
- Bold → *"La energía que transforma empresas."*
- SemiBold → *"Decisiones que generan impacto."*
- Regular → *"Aliados del Sol conecta conocimiento, tecnología y oportunidades para impulsar proyectos sostenibles."*
- Light → *"Información complementaria y textos secundarios."*

Set numérico y de símbolos validado: `0123456789 — $ % + – / kWh MW COP`

> Nota histórica del manual impreso: el manual original de 2023 (Agencia GENOMA) recomendaba **Metropolis** (con Titilium como base) para papelería y piezas impresas complementarias. La actualización digital vigente consolida **Titillium Web** como tipografía única oficial de la marca — usar esta como fuente de verdad para piezas nuevas.

## 5. Estilo visual y fotográfico

A partir de las piezas gráficas de referencia, el sistema visual de Aliados del Sol combina:

- **Fotografía real y humana** (personas en contexto — deportistas, trabajadores, instaladores) sobre fondos de infraestructura solar (paneles, techos industriales).
- **Overlays de color** (degradados azul/morado o naranja/amarillo) aplicados sobre la fotografía para garantizar contraste y legibilidad tipográfica.
- **Titulares grandes y en mayúsculas**, con la cifra o beneficio clave resaltado en color de marca (ej. "HASTA **35 MILLONES** DE PESOS").
- **Numeración circular** (badges redondos en naranja/amarillo) para explicar procesos paso a paso.
- **Contenedores tipo "chat/nota"** (rectángulos con bordes punteados redondeados) para preguntas frecuentes o datos clave.
- **Bloques de color sólido tipo "banner"** con esquinas redondeadas para preguntas destacadas o CTAs.
- **Logo + isotipo GEENERA** siempre presente en el cierre de la pieza, junto a datos de contacto y redes sociales.
- **Íconos simples de línea o sólidos** (apretón de manos, WhatsApp, redes sociales) en el color de marca, nunca a color realista.

## 6. Voz y tono editorial

Basado en el Playbook editorial de GEENERA para Aliados del Sol:

**Principio rector:**
> El contenido no existe para hablar de paneles. Existe para hacer al aliado más útil, confiable y accionable frente a su red.

**North Star del contenido:** aumentar la capacidad del aliado para abrir, sostener o convertir una conversación empresarial, a través de tres movimientos:
1. **Abrir conversaciones** — atención útil: el aliado entiende por qué el tema importa en su realidad profesional.
2. **Elevar criterio** — confianza: datos, herramientas y casos que el aliado puede defender frente a su red.
3. **Mover a acción** — activación: la pieza facilita un siguiente paso concreto.

**Tono general:** directo, ejecutivo, basado en evidencia — nunca "vendedor". Se prioriza el dato con significado, la tesis propia y los frameworks simples (3–7 pasos o señales) sobre el contenido genérico.

**Regla editorial sobre lo "solar":** *"Si quitar 'solar' hace que la pieza deje de tener valor, probablemente era un pitch."* — primero la tensión empresarial real, la energía solar aparece como solución cuando agrega valor genuino, no como eje obligatorio.

**Las 3 audiencias (ICP) y qué protegen:**

| ICP | Qué protege | Lenguaje | Formato fuerte |
|---|---|---|---|
| Financieros | Caja, riesgo, retorno | Flujo, CAPEX, TIR, cartera | Brief, gráfico, webinar |
| Referidos / EMIs | Reputación, relación, trazabilidad | Señales, script, trazabilidad | Checklist, video, WhatsApp |
| Gremios | Valor al afiliado, agenda, impacto | Competitividad, sector, afiliado | Informe, carrusel, evento |

## 7. Aplicación correcta del logo — resumen rápido

✅ Usar el archivo maestro vectorial, sin recrear el símbolo a mano.
✅ Respetar el área de seguridad alrededor del logo.
✅ Usar la versión de color sobre fondos claros; blanco/negativo sobre fotografía oscura.
✅ Mantener siempre la relación de aspecto original.

🚫 No estirar, rotar ni distorsionar el símbolo.
🚫 No cambiar la tipografía del wordmark.
🚫 No aplicar sombras, brillos ni efectos 3D.
🚫 No usar colores fuera de la paleta oficial sobre el logotipo.
🚫 No superponer el logo sobre fondos que reduzcan su legibilidad sin un contenedor de contraste.

## 8. Checklist antes de diseñar una pieza nueva

- [ ] ¿Cuál es el objetivo de la pieza? (descubrimiento, autoridad, profundidad o conversión)
- [ ] ¿A qué ICP se dirige? (Financieros / Referidos-EMIs / Gremios)
- [ ] ¿En qué canal vive? (LinkedIn, activo descargable, WhatsApp/email, evento)
- [ ] ¿Cuál es el mensaje principal y la cifra o dato clave a destacar?
- [ ] ¿La jerarquía tipográfica sigue Titillium Web (Bold → SemiBold → Regular → Light)?
- [ ] ¿Los colores usados están dentro de la paleta oficial (incluyendo overlays)?
- [ ] ¿El logo está en su versión correcta y con área de seguridad respetada?
- [ ] ¿La pieza es coherente con piezas anteriores pero no una copia literal?
- [ ] ¿Si se quita "solar", la pieza sigue teniendo valor por sí misma? (evitar que se sienta como pitch)
